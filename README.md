# 百冊リスト

近藤康太郎『百冊で耕す』の方法論で選んだ、自分用の100冊読書チェックリスト。

## 使い方

1. `https://artista03.github.io/100books/` にアクセス
2. 初回のみGitHub Personal Access Token（scope: `public_repo`）を入力
3. チェックボックスを押すと自動でこのリポジトリの `books.json` に保存される
4. 別のデバイスでアクセスすれば同じ状態が見える

## トークン作成
[こちら](https://github.com/settings/tokens/new?scopes=public_repo&description=100books) から。
